# jrs_wildhorse

jrs_wildhorse for JRS Core - free RedM roleplay framework. English + Arabic.

## Install

1. Copy the `jrs_wildhorse` folder into your server `resources`.
2. Add `ensure jrs_wildhorse` to `server.cfg`.

Requires **jrs_core**, **jrs_inventory** and **oxmysql** from [JRS Core](https://github.com/JRS-CORE/jrscore). Part of [JRS Core](https://github.com/JRS-CORE/jrscore).
